pismoports
==========

Getting a PowerBook Pismo running Mac OS X 10.4 to a usable state for writing
papers — git, subversion, LaTeX, TeXShop — without doing the compiling on the
Pismo. See https://pismoforever.blogspot.com/

The Pismo is a 400–550 MHz G3. Building the ~300 ports that closure implies on
that machine is measured in days, so the point of this repo is to move the
work somewhere faster and ship the Pismo something it can just install.
