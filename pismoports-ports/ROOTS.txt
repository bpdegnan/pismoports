git

TeXShop

# Editor. vim 9.1 has +job/+channel, so asynchronous linting (ALE driving
# chktex, gcc -fsyntax-only, ...) works without a language server -- which
# matters because no LSP server is realistically runnable on a G3.
vim

# Second editor, being attempted rather than assumed. The blocker was always
# LuaJIT, which neovim embeds as its scripting engine -- a JIT with a
# hand-written assembler backend per architecture, and upstream LuaJIT does not
# list Darwin/PowerPC among its supported targets. But MacPorts' luajit port
# sets no known_fail and no supported_archs, and carries a powerpc.patch, so
# it does not consider ppc broken. luajit's own dependencies are only gcc14,
# libgcc and legacy-support, all of which are built -- so this is one build to
# try, not a dependency excavation.
#
# If luajit will not go, neovim can be built against plain Lua 5.1 with
# -DPREFER_LUA=ON; that needs Portfile surgery (the port hardcodes
# luv-luajit) and gives up the JIT, but it is a supported upstream mode.
neovim

# pkill/pgrep, which Tiger does not ship. Installed on yebisu by hand; listed
# here so regenerating the tree does not prune it back out.
proctools

# Circuit simulator, so paper work can be checked on the Pismo. These come
# from bpdegnan/macportseda, NOT from macports-ports -- eda-ngspice47 installs
# into its own prefix (libexec/eda/ngspice47) and is reached via `port select`.
# It needs the eda-github PortGroup, also copied from that tree, which prints
# "report this to macportseda, not MacPorts trac" on a failed phase.
# Cheaper than the stock ngspice port because it does not depend on
# ngspice-docs, which is what drags in xmlto/w3m/libxslt.
eda-ngspice47
eda-ngspice_select

# A working LaTeX install roughly matching TeX Live's "basic" install
# scheme (plain TeX + core LaTeX + widely-used recommended packages +
# recommended fonts), without the huge lang-*/full collections.
texlive-basic
texlive-latex
texlive-latex-recommended
texlive-fonts-recommended
